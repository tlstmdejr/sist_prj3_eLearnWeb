프로젝트
소개		 수강생(User)·강사(Instructor)·관리자(Admin) 3개 역할을 지원하는 통합 온라인 강의 플랫폼입니다.
강의 등록·결제·수강·테스트·리뷰 등 실제 이러닝 서비스에 필요한 전 기능을 구현하였으며,
Oracle DB 22개 테이블·133개 SQL 쿼리·160+ Java 클래스로 구성된 엔터프라이즈급 프로젝트입니다.
DB 설계
주요 테이블 (22개)
  • 회원 관리: USERS · INSTRUCTOR · MANAGER
  • 강의 관련: LECTURE · CHAPTER · CATEGORY · RELATIVE_SKILL
  • 학습 진도: MY_LECTURE · MY_CHAPTER (PROGRESS 0~100, PROGTIME 초단위)
  • 테스트: TEST · TEST_QUESTION · MY_TEST · TEST_EXAMINATION
  • 결제: MY_CART · PAYMENT_DETAIL · PAYMENT · PAYMENT_DETAIL2
  • 커뮤니티: QUESTION · REVIEW · ANNOUNCEMENT
  • 이력 관리: ATTENDANCE · TRANSMISSION_HISTORY
주요 기능
역할 기능
수강생 (User)
  • 회원가입 / 로그인 (이메일·SMS 인증코드 발송)
  • 강의 목록 검색·필터·페이지네이션 (8개씩)
  • 장바구니 담기 → 결제(카드) → 수강 등록
  • 동영상 강의 시청 + 진도율 실시간 저장
  • 강의 자료(PDF 등) 다운로드
  • 객관식 테스트 응시 → 점수·해설 확인
  • 강의 리뷰(1~5점) 작성·수정·삭제
  • Q&A 게시판 질문 등록
  • 마이페이지 (수강 현황·대시보드·결제 내역·프로필 설정)
강사 (Instructor)
  • 강사 회원가입 → 관리자 승인 대기
  • 강의 등록·수정·삭제 (썸네일, 카테고리, 가격 설정)
  • 챕터 등록 (동영상·문서 파일 업로드, 최대 10MB)
  • 객관식 테스트 문제 출제 (4지선다 + 해설)
  • 수강생 Q&A 답변
  • 강사 대시보드 (강의별 수강 현황·수익 통계)
관리자 (Admin)
  • 회원·강사 계정 활성화/비활성화 관리
  • 강의 승인·반려 (반려 사유 입력)
  • 플랫폼 공지사항 CRUD
  • 관리자 대시보드 (전체 통계·신규 가입·수익 현황)
  • 결제 내역 및 수수료 리포트 조회
핵심 로직
  • 페이지네이션: pageScale() · totalPage() · startNum() · endNum() · pagination2() 메서드로 전 목록에 동일한 페이징 구조 적용
  • 결제 트랜잭션: @Transactional(rollbackFor=Exception.class) – PAYMENT_DETAIL → PAYMENT → PAYMENT_DETAIL2 → MY_LECTURE 순차 삽입, 오류 시 전체 롤백
  • 보안: BCrypt 해싱(비밀번호) + AES-256(이름·이메일 PII 암호화) + 세션 인터셉터 3-Role 분기
  • 학습 진도: MY_CHAPTER 테이블에 PROGRESS(0~100)·PROGTIME(초)·ACTUALTIME 실시간 갱신
  • 테스트 채점: TEST_EXAMINATION에 선택지 기록 → ANS 컬럼 비교로 자동 채점 후 MY_TEST에 SCORE 저장
  • 승인 워크플로우: 강의 APPROVAL 플래그 + REJECT_REASON – 등록 → 심사 → 승인/반려 3단계

트러블
슈팅
  • [결제 동시성 문제] 동일 강의를 장바구니에 중복 담는 경우 INSERT 오류 발생 → MY_CART 테이블에 UNIQUE(USER_ID, LECT_ID) 제약 추가 및 서비스 레이어 중복 체크 로직 선적용으로 해결
  • [파일 업로드 경로 문제] 배포 환경에서 C:/upload/ 절대 경로 불일치 → application.properties에 경로 변수 외부화하여 환경별 설정 분리
  • [AES 암호화 길이 초과] 이름·이메일 암호화 시 VARCHAR2 컬럼 길이 초과 → 컬럼 크기를 암호화 후 Hex 길이 기준으로 재설계 (기존 50 → 200 확장)
